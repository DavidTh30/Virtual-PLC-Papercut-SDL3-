# Virtual PLC (papercut, SDL3)

A simulated Siemens CPU — S7-300 (CPU 314 / 315-2 PN/DP / 317-2 PN/DP), S7-400 (412-2 PN / 414-3 PN/DP / 416-3 PN/DP) or S7-1200 (1211C / 1214C / 1215C / 1217C) or S7-1500 (1511-1 PN / 1513-1 PN / 1515-2 PN / 1516-3 PN/DP / 1518-4 PN/DP) — with its memory sizes, I/O areas, timers / counters, DB limits, accumulators and instruction times. The whole UI is papercut, drawn with BGRABitmap on all cores into an SDL3 window at 60 Hz (vsync). The PLC scan cycle runs in its own thread (1 ms, free run or the model's real cycle time).

Build: `C:\lazarus\lazbuild.exe VirtualPLC.lpi` (needs BGRABitmapPack, SDL3_package, `SDL3.dll` next to the exe).

## Screens
- **S7-1500 rules**: TIA style (`%I0.0`, optimized DBs, PUT/GET, retain flags) but with STL, 2048 S5 timers / counters and 4 accumulators for programs moved from the S7-300/400; a programming error without OB121 goes to STOP, a station failure keeps RUN; forcing on the peripheral; front panel with the display, its keys and the RUN / STOP switch; ports X1 P1R / P2R, X2 P1; S7 connect on rack 0 slot 1. Default I/O: DI32 %I0.0, DQ32 %Q0.0, AI8 %IW4, AQ4 %QW4.
- **CPU**: front panel (S7-300/400 module with SF/BF/MAINT/DC5V/FRCE/RUN/STOP LEDs and the RUN/STOP/MRES key switch; S7-1200 compact CPU with RUN/STOP, ERROR, MAINT and on-board I/O LEDs), CPU model choice, cycle time (model / host / scan period / chart), diagnostic buffer.
- **Program**: blocks (OBs, FCs, FBs), LAD networks (contacts, coils, S/R, P/N, NOT, TON/TOF/TP/TONR, S5 timers SD/SE/SP/SS/SF, CU/CD/SC, CTU/CTD/CTUD, CMP, MOVE, ADD/SUB/MUL/DIV, NORM_X, SCALE_X, CALL, branches) STL networks (S7-300/400/1500) and SCL networks (all families). Monitor: power flow in LAD, RLO / STA / ACCU 1 / ACCU 2 per STL line, the value written / condition tested per SCL line.
- **SCL** (Structured Control Language, IEC 61131-3 ST): `VAR_TEMP` locals (`#i`; also arrays `#t[#i]` and PLC data types `#s.x`, 256 bytes of L), `:=`, `IF/ELSIF/ELSE`, `CASE` with lists and ranges, `FOR .. BY`, `WHILE`, `REPEAT .. UNTIL`, `EXIT`, `CONTINUE`, `RETURN`, `REGION`, `//` and `(* *)` comments; operators with SCL priorities (`**`, unary, `* / MOD`, `+ -`, compare, `AND &`, `XOR`, `OR`); functions ABS SQRT LN EXP SIN … TRUNC ROUND MIN MAX LIMIT SEL NORM_X SCALE_X SHL SHR ROL ROR and `<type>_TO_<type>` conversions; IEC calls `"DB".T.TON(IN := .., PT := .., Q => .., ET => ..)`, `.CTU / CTD / CTUD`, also on instances in arrays: `"DB".Tm[#i].TON(..)`, `"DB".M[#i].T.TON(..)` (every element keeps its own timer state); FC calls; operands `"Tag"`, `"DB".Var`, `"DB".Arr[expression]` and `"DB".Arr[expression].Member.Sub`, also several variable indexes in one operand `"DB".M[#i].Hist[#j]` (each checked against its bounds at run time), `%MW20`. TIA type rules: implicit widening, REAL → INT needs a conversion, conditions must be BOOL; INT wraps at 16 bit, REAL is single precision. Editor with syntax colours, auto indent, Tab = 4 spaces; clicking a compiler message jumps to the line.
- **SCL as in the SCL Compiler** (the elements of SCL Studio, `SCL compiler\SCLCompiler`): typed literals `INT#5`, `UDINT#16#FF`, `BYTE#200`, `BOOL#1`, `REAL#1.5`, `CHAR#'A'`, `8#17`, `D#2024-01-31`, `TOD#12:00:00.5`, `DT#2024-01-31-12:00:00`, `LT#1D2H3M4S5MS6US7NS`, `LTOD#..`, `LDT#..`, numbers above the DInt range (UDInt, LInt, ULInt); `VAR CONSTANT name : Type := value; END_VAR` at the top of a network (`#name`, read only); `MUX(K := .., IN0 := .., .., INELSE := ..)` (also positional); slices `.%X3`, `.%B1`, `.%W0`, `.%D0` read and written (also with a variable index); arrays of more dimensions `Array[0..2, 1..3] of Int` with `"DB".m[1, 2]` / `"DB".m[#i, #j]` (row by row, the last index fastest) and start lists `[1, 2, 3(7)]`; an FC's value as `#<FC name> := ..` (TIA) and FC calls with positional arguments `"F"(2, 3, "DB".o)`; the system FBs as Statics or DB variables, called `#t(IN := .., PT := ..)`: TON_TIME, TOF_TIME, TP_TIME, TONR_TIME, TON_LTIME (ns), CTU_INT / CTD_INT / CTUD_INT and CTU_SINT .. CTU_ULINT (the count in their type), R_TRIG, F_TRIG, RS, SR. **Strings**: `String[n]` / `WString[n]` (max length, length, characters as on the CPU; a String start value `'text'`, `WSTRING#'..'`, `$N $R $T $' $$ $hh / $hhhh`), `Char`, `WChar`, LEN, CONCAT, LEFT, RIGHT, MID, FIND, comparisons (a Char beside a String is one), String parameters of FCs / FBs and the Return value, arrays of strings, a target keeps its own max length. **64 bit and long times** (exact, the SCL stack holds an Int64 beside the Double): LInt, ULInt, LWord, LReal, LTime, LTime_Of_Day, LDT, Date_And_Time (BCD), DTL (12 bytes: YEAR .. NANOSECOND); the time arithmetic of TIA (TOD + TIME stays inside the day, DT / LDT + TIME / LTIME, TOD - TOD = TIME, LTIME and TIME do not mix), TIME_TO_LTIME, LTIME_TO_TIME, DT_TO_LDT, DT_TO_DATE, DT_TO_TOD ...; LInt / LTime / LTOD / LDT only on the S7-1500. The DB screen, the watch table and the monitor show strings as `'text'`, the 64 bit values as `LT#..`, `LDT#..`, `DT#..`, Date / TOD as `D#..` / `TOD#..`, the unsigned ones unsigned; the watch table modifies strings and 64 bit values too.
- **LAD / STL as SCL**: the **boxes of the SCL functions** in LAD (`IsSclBox`, compiled as SCL with the rung as EN / CLK and ENO / Q as the power out, `__RLO__`): SEL, MUX, LIMIT, MIN, MAX; MOD, NEG, INC, DEC, EXPT, ABS, SQR, SQRT, EXP, LN, SIN .. ATAN, FRAC; S_MOVE; SHL, SHR, ROL, ROR, AND / OR / XOR / INV of bit strings; CONCAT, LEN, LEFT, RIGHT, MID, FIND; R_TRIG, F_TRIG, RS, SR (with their instance); every type SCL has (strings, 64 bit). The TON / TOF / TP / TONR / CTU / CTD / CTUD boxes take the instances of TIA too (TON_LTIME with LT#, CTU_DINT ..; the box shows the type). **STL**: `CALL SEL` / `CALL MUX` / `CALL LIMIT` / `CALL MIN` .. / `CALL CONCAT` / `CALL LEN` / `CALL NORM_X` / `CALL INT_TO_REAL` ... with one parameter per line (`IN0 := ..`, the result `RET_VAL := ..` or `OUT := ..`, `value_type := Int` is taken and left), and `CALL #Delay` / `CALL "DB".Edge` of a TON_TIME, CTU_INT, R_TRIG, RS .. instance (`IN := ..`, `PT := ..`, `Q := ..`).
- **LAD / STL / SCL elements panels**: the same list for every language, in categories: LAD (bit logic, edges, timers, counters, comparison / selection, math, move / conversion, shift / word logic, string, program control, keys and the project: its tags / DB variables as operands, its FCs and instance DBs as CALL boxes; only what the CPU family has) and STL (bit logic, load / transfer, S5 timers / counters, integer / real math, comparison, conversion, word logic / shift, jumps, blocks, the SCL functions as CALL, the system FBs as CALL, keys, the project); LAD: a double click puts the element into the selected cell (a name: the operand of the selected element), a drag by the grip drops it onto a cell; STL as SCL (the code at the caret). The cell's properties stay below the LAD list.
- **Organization blocks** (`uobcatalog.pas`, **+ OB (organization block) ...**): the standard OBs of each CPU family by event, with their numbers, names and priorities: S7-300 (OB1, OB10, OB20, OB35, OB40, OB55..57, OB61, OB80..87, OB100, OB121, OB122), S7-400 (also OB10..17, OB20..23, OB30..38, OB40..47, OB60..64, OB88, OB90, OB101, OB102), S7-1200 (OB1, OB10..17, OB20..23, OB30..38, OB40..47, OB55..57, OB80, OB82, OB83, OB86, OB100) and S7-1500 (also OB61..64, OB121, OB122). An OB of its own number (123 .. 32767, S7-1200 / 1500) can be a program cycle, startup, time of day, time delay, cyclic, hardware interrupt or synchronous cycle OB. The dialog shows which OBs the project has, the name, the language of the first network and what starts the OB in the Virtual PLC.
- **The interface of an OB**: its **start information**, written by the CPU when the OB starts and not edited: S7-1200 / 1500 in the Input section (`#Initial_Call`, `#Remanence`; cyclic `#Event_Count`; hardware `#LADDR`, `#IChannel`, `#EventType`; time delay `#Sign`; OB80 `#fault_id`; OB82 / 83 / 86 `#Event_Class`, `#Fault_ID`; OB121 / 122 `#BlockNr`, `#Fault_ID`, `#Csg_OBNr` ..), S7-300 / 400 in the first 20 bytes of the Temp (`#OB1_EV_CLASS`, `#OB1_SCAN_1`, `#OB1_PREV_CYCLE`, `#OB35_EXC_FREQ`, .. `#OBnn_DATE_TIME`); the user's Temps follow (L20 on the S7-300/400). It changes with the CPU family. Above the rows: the OB's event and its settings: the cycle time and phase of a cyclic interrupt, the input bit and the edge of a hardware interrupt, the start, interval and on / off of a time of day interrupt, the SRT_DINT call of a time delay interrupt; and how often the OB ran.
- **The OBs in the runtime**: every program cycle OB after OB1 (by number), every startup OB after OB100, each cyclic interrupt with its own time and phase (missed starts count in `#Event_Count`), hardware interrupts on the edges of their input, time of day interrupts from the PC clock, time delay interrupts by `SRT_DINT(OB_NR := 20, DTIME := T#2S, SIGN := 16#0)` (`CAN_DINT` cancels); OB80 when the cycle time is exceeded (the CPU stays in RUN, the watchdog starts again once), OB121 / OB122 on a programming / I/O access error (the program goes on after the instruction), OB86 on the station failure and return, OB82 / OB83 from **Diag. interrupt** / **Pull module** in the I/O screen's Fault injection (S7-300/400 without the OB: STOP). Every interrupt is transparent for the block it interrupts.
- **SCL parameter help** (`usclsig.pas`): in a call (`"Motor_DB"(`, `#Delay(` of a TON_TIME, `"Fc"(`, `SEL(`, `LIMIT(`, `SRT_DINT(`, `INT_TO_REAL(` ..) a box above the line shows the parameters with their direction and type, the one at the caret in red, its comment and the variables of the project that fit its type (`fits: #SetSpeed, "Box".Picked ..`). A grey **ghost** after the caret shows what comes: after `(` every parameter (`Run := <Bool>, Speed := <Int>, Running => <Bool>);`), at a new argument the next parameter, in a value a variable of the right type, else the rest of a word (`#Set` → `Speed`, `"Mot` → `or_DB"`). **Tab** inserts it: a call gets one parameter per line, aligned, with TIA's placeholders (`_bool_in_`, `_int_in_`, `_bool_out_`) and the first placeholder selected, so typing replaces it; Tab again selects the next placeholder. **Esc** hides the ghost and the box at that place.
- **Cross reference** (`uxref.pas`, **F11**, or the right button: the code's text menu, a LAD element, an interface row, an I/O channel (DI, DQ, AI, AQ, a tag I/O row, a signal row), a tag, a DB variable, a watch row, a row of the editor's Variables): every place the operand is used, matched by its symbol and its address (`"Motor"` = `Q4.0` = `%Q4.0`; a byte / word over the bit shows as *overlaps*). Filters: all / decisions / destinations / tables and declarations; a click on a row goes there (the block, the network, the line or the LAD cell; the table row). Esc closes.

## Sample (motor start / stop)

The program starts with an empty S7-1200 project (CPU 1214C, OB1 "Main" with one LAD network), downloaded to the CPU in STOP.
FC1 "SpeedStats" (calling FC2 "Clamp" with a Return value for the average and FB1 "RunMeter" with its instance DB2 "RunMeter_DB" for the run seconds) is written in SCL in every family's sample (called from OB1 with a LAD CALL box): speed history in an array of the PLC data type "SpeedSample" (Rpm, Running) with a FOR loop and a variable index, the average, a CASE speed class, and FB1 whose static IEC timer counts the motor seconds.

Load it on the Project screen (or `--sample=300|400|1200`), press RUN (F5), then on I/O: turn **Overload_OK** (I0.2) on and press **Start_PB** (I0.0). The motor latches (Stop_PB I0.1 is a NC button), the 5 s timer switches **Full_Speed**, every start is counted (service after 5), the starting lamp flashes on the 1 Hz clock memory bit, the analog speed is scaled to rpm, and the cyclic interrupt counts run time.
