##############################################################################################################
1. บทสรุป (Executive Summary)
##############################################################################################################

โฟลเดอร์ PLC_S7-1200 คือชุดโปรแกรม PLC สำหรับระบบ Fluff Silo บน Siemens S7-1200 เขียนด้วยภาษา SCL ในรูปแบบ External
source (นำเข้า TIA Portal V16 ขึ้นไป แล้ว Generate blocks from source) ควบคุมอุปกรณ์ 5 ตัว ได้แก่ Blower01, Screw01,
Paddle01, Paddle02 และ Paddle03 ระบบมีลำดับ Auto Start / Auto Stop, Paddle Patterns ที่ตั้งค่าได้ (สูงสุด 10 step),
ระบบ Priority L1–L6 ต่ออุปกรณ์, การตรวจจับ Fault จาก overload และ running feedback, การควบคุมระดับไซโล
(Fill_Request) และ interface กับ FluffSilo HMI ผ่าน DB10 แบบ PUT/GET

4.2 หลักการออกแบบที่ใช้ (ควรรักษาไว้เมื่อพัฒนาต่อ)
----------------------------------------

  • ทุก I/O อ้างอิงด้วยชื่อ tag เท่านั้น อยู่ใน FB_FluffSilo ที่เดียว — FB ย่อยไม่แตะ I/O โดยตรง ทำให้ทดสอบและนำกลับมาใช้ได้
  • FB ย่อยทั้งหมดเป็น multi-instance ใน FB_FluffSilo → มี instance DB เดียว (iDB_FluffSilo)
  • ข้อมูลที่ HMI ต้องเห็น/แก้ อยู่ใน DB_HMI (absolute address) ส่วน state ภายในอยู่ใน iDB (optimized) แยกกันชัดเจน
  • คำสั่งจาก HMI เป็น pulse และ PLC เป็นผู้ล้าง (acknowledge) — ไม่มีคำสั่งค้างแม้ HMI หลุด
  • การตั้งค่าเวลาใช้หน่วย 0.1 s แบบ Int ใน DB_HMI แล้วแปลงเป็น TIME ด้วย FC_TenthsToTime
  • ใช้ REGION แบ่งส่วนโค้ด และ comment ภาษาอังกฤษในหัวไฟล์อธิบายพฤติกรรม
  • ค่า Available ของ Paddle ใช้ค่าจาก scan ก่อนหน้า (หลีกเลี่ยง algebraic loop ระหว่าง Pattern ↔ Motor)


4.3 ลำดับการทำงานใน 1 scan (FB_FluffSilo)
----------------------------------------

  [รูปที่ 3 การไหลของสัญญาณภายใน FB_FluffSilo]  → images/03_signal_flow.png
 Inputs ─► ① E-Stop latch ─┐
        ─► ② ExtReq + Params (Validate, Tenths→TIME)
        ─► ③ #Seq (FB_Sequencer) ── PatternCmd ─► ④ #Pattern ── PaddleCmd[0..2] ─┐
                         └── Blower/Screw AutoStart/Stop/Interlock ─────────────────┤
                                                                                     ▼
        FB/OL + DevCmd ─────────────────────────────────────────────► ⑤ FB_Motor ×5 ─► ⑥ Q0.0..Q0.7
                         ◄── Available (scan ถัดไป) ───────────────────┘
 IW64 ─► ⑦ FC_ScaleAnalog + hysteresis ─► Q1.0 Fill_Request
 ⑧ Status → DB_HMI.Dev/Sys/Proc     ⑨ ล้าง Cmd/DevCmd (pulse)

+------+---------------------------------+-------------------------------------------------------------------+
| ลำดับ | REGION                          | การทำงาน                                                          |
+======+=================================+===================================================================+
| ①    | E-Stop and reset                | R_TRIG ของ (PB_Reset OR Cmd.ResetEStop) → #resetPulse; EStop_OK=0 |
|      |                                 | หรือ Cmd.EStop → latch; reset ได้เมื่อ EStop_OK=1 และไม่มี Cmd.EStop    |
+------+---------------------------------+-------------------------------------------------------------------+
| ②    | External Request and parameters | #extReq = ExtRequest_In OR Cmd.ExtRequest; FC_ValidateParams;     |
|      |                                 | แปลง Delay[0..5] เป็น TIME                                         |
+------+---------------------------------+-------------------------------------------------------------------+
| ③    | Auto sequence                   | #cmdStop = Cmd.AutoStop OR NOT PB_AutoStop(NC); #cmdStart =       |
|      |                                 | (Cmd.AutoStart OR PB_AutoStart) AND NOT #cmdStop → #Seq           |
+------+---------------------------------+-------------------------------------------------------------------+

  4. Pattern 4 Paddle: ขยาย Mask เป็น bit3, เปลี่ยน FC_StepBlocked (W#16#000F, Available[0..3]),
     FB_PaddlePattern (Available/PaddleCmd [0..3]), FC_ValidateParams (Mask MX := 15)
  5. อัปเดต AnyFault, HMI register map และ README; ทดสอบ scenario Paddle fault/skip ใหม่


10.3 วิธีเพิ่มจำนวน step ของ Pattern (> 10)
---------------------------------------

  1. ขยาย Pattern.Mask / StepTime ใน DB_HMI — กระทบ offset StepTime (DBW62) ต้องพิจารณาย้ายตาราง Pattern ไปท้าย
     DB หรือสร้าง DB ใหม่
  2. แก้ค่าคงที่ 10 และ 9 ใน FB_PaddlePattern (LIMIT MX := 10, Array[0..9]), FC_ValidateParams, FC_LoadDefaults
  3. แนะนำใช้ค่าคงที่ (User constant) เช่น PATTERN_MAX_STEPS แทนตัวเลขตายตัว


10.4 วิธีเปลี่ยน Level sensor เป็น 4-20 mA
-------------------------------------

  1. ใส่ SB 1231 AI1 หรือ SM 1231 AI4 ตั้งช่วง 4-20 mA, แก้ address ของ Silo_Level_AI
  2. ใน FC_ScaleAnalog ค่า 4-20 mA ก็สเกล 0..27648 เหมือนเดิม; สายขาดจะได้ 32767 (overflow) หรือ -32768 ขึ้นกับโมดูล →
     Fault ทำงาน
  3. เปิด diagnostic 'wire break' ใน hardware config ของโมดูล


10.5 ข้อแนะนำด้านคุณภาพโค้ด
-----------------------

  • ตั้ง Know-how / version ของ block (VERSION : 0.1 ทุกไฟล์) และใช้ระบบ version control (Git) สำหรับไฟล์ .scl
  • สร้าง Watch table / Force table มาตรฐานสำหรับ commissioning
  • เขียน unit test ด้วย PLCSIM + Test Suite (TIA V17+) หรือคงโมเดล Python ที่ใช้จำลอง 31 scenario ไว้ในโปรเจกต์
  • ใช้ค่าคงที่แทน magic number (dev×8+cmd, 27648, 10 steps)
  • พิจารณาใช้ FB_Motor เป็น Library type (Global library) เพื่อควบคุมเวอร์ชัน

11. ขั้นตอนนำเข้า TIA Portal (สรุปจาก README)
##############################################################################################################

  1. Add device: CPU 1214C DC/DC/RLY + SM 1221 DI8 ที่ slot 2 (ตรวจ I8.0, AI0 0-10 V ที่ IW64)
  2. CPU Properties → Protection & Security → Connection mechanisms → ติ๊ก Permit access with PUT/GET; ตั้ง IP

  7. Compile (rebuild all) → Download → RUN
  8. FluffSilo HMI: Protocol Siemens S7, IP ของ PLC, Port 102, Rack 0 / Slot 1, ใช้ register map DB10

13. ข้อควรระวังด้านความปลอดภัย
##############################################################################################################

  • E-Stop ต้องเป็นวงจร hardware (safety relay ตัดไฟ contactor) ตาม risk assessment — S7-1200 มาตรฐานไม่ใช่
    safety PLC
  • iDB_FluffSilo เป็น NON_RETAIN โดยตั้งใจเพื่อไม่ให้เครื่องสตาร์ทเองหลังไฟกลับ — อย่าเปลี่ยนเป็น retain
  • ก่อนใช้งานจริงควรตั้ง SafeInterlock = TRUE และ RestartAfterBlowerTrip = FALSE
  • เปิด PUT/GET ทำให้ใครก็ตามในเครือข่ายเขียน DB ได้ — แยก VLAN/firewall สำหรับเครือข่ายเครื่องจักร
  • ทดสอบโดยปลด power มอเตอร์ หรือใช้ Force อย่างระมัดระวัง
