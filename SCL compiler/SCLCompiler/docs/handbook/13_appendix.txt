Glossary
--------------------

+-----------------------------+------------------------------------------------------------------------------+
| คำ                          | ความหมาย                                                                     |
+=============================+==============================================================================+
| SCL                         | Structured Control Language — ภาษาแบบ ST (IEC 61131-3) ของ Siemens           |
+-----------------------------+------------------------------------------------------------------------------+
| OB / FB / FC / DB / UDT     | Organization block / Function block (มี instance) / Function / Data block /   |
|                             | PLC data type                                                                |
+-----------------------------+------------------------------------------------------------------------------+
| Instance DB                 | DB ที่เก็บหน่วยความจำของ FB หนึ่งตัว                                                |
+-----------------------------+------------------------------------------------------------------------------+
| Multi-instance              | FB ซ้อนอยู่ใน static ของ FB อื่น                                                  |
+-----------------------------+------------------------------------------------------------------------------+
| Standard / optimized access | DB ที่มี offset ตายตัว (HMI ใช้ address ได้) / ไม่มี offset ภายนอก                   |
+-----------------------------+------------------------------------------------------------------------------+
| Retain                      | ค่าที่คงอยู่หลังไฟดับ                                                               |
+-----------------------------+------------------------------------------------------------------------------+
| Image (.svpl)               | ไฟล์ผลลัพธ์ของ compiler ที่ Virtual PLC โหลด                                      |
+-----------------------------+------------------------------------------------------------------------------+
| Pending frame               | frame ของ FC ที่ caller จองเพื่อใส่ parameter ก่อนเรียก                             |
+-----------------------------+------------------------------------------------------------------------------+
| Download                    | ส่ง image จาก IDE ไปยัง Virtual PLC                                            |
+-----------------------------+------------------------------------------------------------------------------+
| PUT/GET                     | บริการอ่าน/เขียนหน่วยความจำของ S7 ที่ HMI ใช้                                       |
+-----------------------------+------------------------------------------------------------------------------+


รูปแบบไฟล์ .sclproj
--------------------

    [Project]
    Name=FluffSilo
    CPU=S7-1200
    OutputDir=output
    [Sources]
    File1=02_UDT_typeDevStatus.scl
    [Tags]
    File1=01_PLC_Tags.csv
    [BlockNumbers]
    DB_HMI=10
    [CyclicInterval]
    Cyclic interrupt=100


รูปแบบ tag CSV
--------------------

    Name;Path;Data Type;Logical Address;Comment;Value
    EStop_OK;FluffSilo_IO;Bool;%I0.0;Safety relay OK;
    MAX_SPEED;Constants;Int;;user constant;1500


คำสั่ง CLI
--------------------

+-----------------------------------------------------------------+------------------------+
| คำสั่ง                                                            | ผล                     |
+=================================================================+========================+
| sclc p.sclproj [-o x.svpl] [-l x.lst] [--check] [--cpu S7-1500] | compile                |
+-----------------------------------------------------------------+------------------------+
| sclc --import <folder> --cpu S7-1200 -p p.sclproj               | สร้างโปรเจกต์จากโฟลเดอร์  |
+-----------------------------------------------------------------+------------------------+
| sclc --dump x.svpl                                              | แสดงเนื้อหา image        |
+-----------------------------------------------------------------+------------------------+
| sclc --sim x.svpl --script t.txt                                | รันทดสอบ                |
+-----------------------------------------------------------------+------------------------+
| sclc p.sclproj --check --find-decl file:line:col                | ทดสอบ Find Declaration |
+-----------------------------------------------------------------+------------------------+


คีย์ลัด SCL Studio
--------------------

+---------------------------+-----------------------------------+
| คีย์                        | คำสั่ง                              |
+===========================+===================================+
| Ctrl+O / Ctrl+S           | Open project / Save all           |
+---------------------------+-----------------------------------+
| Ctrl+N                    | New block                         |
+---------------------------+-----------------------------------+
| Ctrl+T                    | Tags                              |
+---------------------------+-----------------------------------+
| F7 / F9                   | Compile / Build                   |
+---------------------------+-----------------------------------+
| F11 / F12                 | All variables / All elements      |
+---------------------------+-----------------------------------+
| Alt+1 / Alt+2             | Project tree / SCL elements panel |
+---------------------------+-----------------------------------+
| Alt+Up, Ctrl+Click        | Find Declaration                  |
+---------------------------+-----------------------------------+
| Alt+Left                  | Go Back                           |
+---------------------------+-----------------------------------+
| Ctrl+F / F3               | Find / Find next                  |
+---------------------------+-----------------------------------+
| Ctrl+W                    | Close tab                         |
+---------------------------+-----------------------------------+
| Enter / Ctrl+Enter (tree) | เปิด source / interface editor     |
+---------------------------+-----------------------------------+
