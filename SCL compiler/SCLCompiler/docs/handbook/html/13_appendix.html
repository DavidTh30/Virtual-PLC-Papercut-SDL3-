Glossary

คำความหมาย
SCLStructured Control Language — ภาษาแบบ ST (IEC 61131-3) ของ Siemens
OB / FB / FC / DB / UDTOrganization block / Function block (มี instance) / Function / Data block / PLC data type
Instance DBDB ที่เก็บหน่วยความจำของ FB หนึ่งตัว
Multi-instanceFB ซ้อนอยู่ใน static ของ FB อื่น
Standard / optimized accessDB ที่มี offset ตายตัว (HMI ใช้ address ได้) / ไม่มี offset ภายนอก
Retainค่าที่คงอยู่หลังไฟดับ
Image (.svpl)ไฟล์ผลลัพธ์ของ compiler ที่ Virtual PLC โหลด
Pending frameframe ของ FC ที่ caller จองเพื่อใส่ parameter ก่อนเรียก
Downloadส่ง image จาก IDE ไปยัง Virtual PLC
PUT/GETบริการอ่าน/เขียนหน่วยความจำของ S7 ที่ HMI ใช้

คำสั่ง CLI

คำสั่งผล
sclc p.sclproj [-o x.svpl] [-l x.lst] [--check] [--cpu S7-1500]compile
sclc --import <folder> --cpu S7-1200 -p p.sclprojสร้างโปรเจกต์จากโฟลเดอร์
sclc --dump x.svplแสดงเนื้อหา image
sclc --sim x.svpl --script t.txtรันทดสอบ
sclc p.sclproj --check --find-decl file:line:colทดสอบ Find Declaration
