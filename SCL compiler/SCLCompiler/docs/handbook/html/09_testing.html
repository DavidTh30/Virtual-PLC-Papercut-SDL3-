คำสั่งความหมาย
cycle-ms 10เวลาจำลองต่อ cycle
set <path> <value>เขียน tag หรือ "DB".path
link <input> <output>input = output ทุก cycle (จำลอง feedback)
run 7s | run 500ms | run 3 cyclesรัน
expect <path> <value>PASS / FAIL
print <path>แสดงค่า
echo textข้อความ

วิธีเพิ่ม test

  1. สร้างโปรเจกต์ใน examples/<ชื่อ> (หรือใช้ sclc --import)
  2. เขียน tests/<ชื่อ>.txt ด้วยคำสั่งข้างบน
  3. เพิ่มใน run_tests.bat
  4. ทุกครั้งที่แก้ codegen หรือ opcode ให้รัน run_tests.bat
