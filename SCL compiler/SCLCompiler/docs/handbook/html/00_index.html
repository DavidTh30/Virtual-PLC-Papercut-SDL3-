สารบัญและวิธีใช้เอกสาร

เอกสารชุดนี้สรุปโปรแกรม SCL Compiler + SCL Studio ที่สร้างด้วย Lazarus / Free Pascal อย่างละเอียด เพื่อใช้พัฒนาต่อ รวมถึงการออกแบบ Virtual PLC ที่รองรับการ Download ไฟล์ image จาก IDE

ไฟล์หัวข้อเหมาะกับ
01_overviewภาพรวมโครงการ สถานะ สถิติ โครงสร้างโฟลเดอร์ เริ่มใช้งานทุกคน
02_architectureสถาปัตยกรรม compiler, pipeline, unit และ dependencyผู้พัฒนา compiler
03_languageภาษา SCL ที่รองรับ กฎตาม CPU และข้อจำกัดผู้ใช้ / ผู้พัฒนา
04_compiler_internalsรายละเอียดภายใน: lexer, parser, type system, layout, codegenผู้พัฒนา compiler
05_image_formatรูปแบบไฟล์ .svpl และ memory modelผู้พัฒนา Virtual PLC
06_instruction_setInstruction set, call convention, system FBผู้พัฒนา Virtual PLC
07_virtual_plcโครงสร้าง Virtual PLC และการรองรับ Download (protocol, validation, mode)ผู้พัฒนา Virtual PLC
08_user_interfaceUI ปัจจุบันของ IDE และ UI พื้นฐานที่ต้องมี (IDE online + Virtual PLC)ผู้ออกแบบ UI
09_testingชุดทดสอบ ภาษา script และวิธีเพิ่ม testผู้พัฒนา / QA
10_developer_guideคู่มือแก้ไข/เพิ่ม feature, coding convention, ข้อควรระวัง FPC/LCLผู้พัฒนา
11_recommendationsคำแนะนำ ความเสี่ยง และ Roadmapหัวหน้าโครงการ
12_referencesแหล่งข้อมูลที่ใช้สร้างแต่ละหัวข้อ และเอกสารที่ควรใช้ตรวจสอบทุกคน
13_appendixGlossary, รูปแบบไฟล์ project/tag, คำสั่ง CLI, คีย์ลัดทุกคน

ทุกหัวข้อมีทั้งไฟล์ .txt (อ่านด้วย text editor) และ .pdf (มีรูปภาพ) และมีไฟล์รวม SCL_Compiler_Handbook.pdf / .txt รูปภาพทั้งหมดอยู่ในโฟลเดอร์ images/ ทั้งแบบ .svg (แก้ไขได้) และ .png

สถานะความถูกต้อง: compiler ถูกทดสอบด้วยโปรแกรมจริง (FluffSilo, 14 block) และชุดทดสอบภาษา บน reference Virtual PLC ที่อยู่ในโปรเจกต์ แต่ยังไม่ได้เทียบผลกับ TIA Portal หรือ PLC จริง ส่วนการออกแบบ Virtual PLC / Download ในหัวข้อ 07 เป็นข้อเสนอ (ยังไม่ได้ implement)
