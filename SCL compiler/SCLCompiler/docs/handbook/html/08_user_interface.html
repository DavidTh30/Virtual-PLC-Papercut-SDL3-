User Interface

UI ปัจจุบันของ SCL Studio

ส่วน UIความสามารถ
ToolbarNew project, Open, Save all, New block, Tags, Compile, Build, Variables, All elements, Project tree, SCL elements, CPU
Project tree (Alt+1)PLC tags, UDT, Program blocks (OB/FB/FC/DB พร้อมเลข), Source files; context menu: open, interface, set number, remove
SCL editorsyntax highlight, auto highlight ชื่อ, Find Declaration (คลิกขวา / Alt+Up / Ctrl+Click), Go Back (Alt+Left), Find, Undo/Redo
SCL elements (Alt+2)20 หมวด พับ/ขยาย ค้นหา ลากวาง / ดับเบิลคลิก, หมวด Project อัปเดตตาม compile
Messageserror/warning ดับเบิลคลิกไปบรรทัด
ViewsAll variables, All elements, Listing, Tags, Interface grid
FileRecent projects / Recent files, import tags, add source

UI พื้นฐานที่ IDE ต้องเพิ่มเพื่อทำงานกับ Virtual PLC

ลำดับความสำคัญUIรายละเอียด
สูงOnline menu + toolbarConnect/Disconnect, Download (F10), RUN, STOP, สถานะการเชื่อมต่อใน status bar
สูงConnection settingsIP, port, password, timeout; จำค่าไว้ในโปรเจกต์
สูงDownload dialogเทียบ CPU/hash, ตัวเลือก STOP ก่อนโหลด / keep retain / reset DB / START หลังโหลด, progress, log
สูงDiagnostic buffer viewerแสดงเหตุการณ์จาก Virtual PLC, ดับเบิลคลิกไป block/line
กลางWatch / force tableเพิ่ม path จาก All variables / Find Declaration, monitor ทุก 200 ms, modify, force
กลางOnline status ใน editorแสดงค่าตัวแปรข้างบรรทัดตาม line table, สีของเงื่อนไข
กลางCompare offline/onlinehash ทั้งไฟล์และต่อ block
ต่ำUploadดึง image จาก Virtual PLC (ดูได้แต่ไม่มี source)

UI พื้นฐานของ Virtual PLC

ส่วนต้องมี
StatusRUN / STOP / ERROR LED, cycle time min/avg/max, ชื่อ image, hash, เวลาที่โหลด, จำนวน connection
Modeปุ่ม RUN / STOP / MRES, cold / warm restart, auto start เมื่อเปิดโปรแกรม
I/O panelcheckbox ของ input (จาก TAGS), lamp ของ output, slider ของ analog — ใช้ทดสอบเมื่อไม่มี hardware
Watch / forceตารางตัวแปรตาม path พร้อมค่า และ force
DB viewerดู DB เป็นตาราง (จาก vars) และ hex
Diagnostic bufferประวัติเหตุการณ์ export ได้
Settingsport, password, cycle/watchdog, retain path, I/O driver, S7 server on/off
แหล่งข้อมูลของหัวข้อนี้
  • ภาพหน้าจอจากการรัน bin/SCLStudio.exe จริง
  • wireframe ออกแบบใหม่ในเอกสารนี้
  • แนวคิด UI ของ TIA Portal (Online & diagnostics, Watch table, Force table) และ PLCSIM เป็นแรงบันดาลใจ — ไม่ได้คัดลอกหน้าจอ
