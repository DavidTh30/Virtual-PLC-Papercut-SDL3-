คำแนะนำและ Roadmap

คำแนะนำสำคัญ

  1. ตรวจกับของจริงก่อนขยาย: import FluffSilo เข้า TIA Portal เทียบ offset ของ DB และพฤติกรรม (PLCSIM) เพื่อยืนยันกฎ layout/conversion
  2. สร้าง Virtual PLC จาก scl_vm.pas ก่อน (ทำงานถูกแล้วกับ 109 checks) แทนการเขียนใหม่
  3. ทำ Download แบบ STOP-only ก่อน, run-time download ไว้ทีหลัง
  4. เพิ่ม layout hash ต่อ DB และ hash ทั้ง image (SVPL v2) เพื่อ keep retain และ compare online/offline อย่างปลอดภัย
  5. ล็อก format: ทุกการเปลี่ยน opcode/section ต้องเพิ่ม version และมี test
  6. ความปลอดภัย: Virtual PLC ห้ามใช้แทน safety PLC / E-Stop ต้องเป็น hardware; เปิด password และจำกัด network ของ PUT/GET
  7. ประสิทธิภาพ: ถ้า cycle ยาว ให้ทำ pre-decode bytecode เป็น array ของ record (ไม่ต้องอ่าน operand ทุกครั้ง) ก่อนคิด JIT
  8. License: Lazarus LCL (modified LGPL), SynEdit (MPL/GPL dual), Snap7 (LGPL3) — ตรวจเงื่อนไขก่อนแจกจ่ายเชิงพาณิชย์

ความเสี่ยง

ความเสี่ยงผลกระทบการลด
พฤติกรรมต่างจาก S7 จริง (rounding, overflow, timer edge)โปรแกรมทำงานต่างกันgolden test กับ PLCSIM
Feature ภาษาที่ยังไม่รองรับimport โปรแกรมเดิมไม่ได้จัดลำดับตามโปรแกรมจริงที่ใช้
Download ทำ image เสียเครื่องหยุดvalidator + atomic swap + เก็บ image เดิม
Retain หายค่าตั้งหายretain.bin + CRC + layout hash
Network ไม่ปลอดภัยมีคนแก้โปรแกรมpassword, session lock, จำกัด IP
