ภาพรวมโครงการ

เป้าหมาย

  • แปลงโปรแกรม SCL ของ Siemens (S7-300 / S7-400 / S7-1200 / S7-1500) ในรูปแบบ "External source" ของ TIA Portal ให้เป็น bytecode
  • ให้มี IDE ภาษาไทย/อังกฤษสำหรับเขียน แก้ไข ตรวจ และ build โปรแกรม SCL โดยไม่ต้องใช้ TIA Portal
  • ผลลัพธ์เป็นไฟล์ image (.svpl) ที่ Virtual PLC (พัฒนาภายหลัง) โหลดและรันได้
  • โครงสร้างหน่วยความจำ DB แบบ standard access ตรงกับ S7 เพื่อให้ HMI เดิมอ่าน/เขียนด้วย address เดิมได้

สิ่งที่ทำเสร็จแล้ว

ส่วนสถานะหมายเหตุ
Lexer / Parser SCL ครบทุก blockเสร็จTYPE, DATA_BLOCK, FUNCTION, FUNCTION_BLOCK, ORGANIZATION_BLOCK
Semantic + type checking ตาม CPUเสร็จerror พร้อม file(line,col), ไม่หยุดที่ error แรก
Memory layout แบบ S7 standardเสร็จDB_HMI 82 byte ตรงกับ HMI map ทุก offset
Code generator → bytecodeเสร็จ91 opcode, system FB 15 ชนิด
ไฟล์ image .svpl + listing + memory mapเสร็จreader/writer แยก unit ใช้กับ Virtual PLC ได้
Reference Virtual PLC (interpreter)เสร็จ (ทดสอบ)ใช้ทดสอบ compiler; เป็นต้นแบบของ Virtual PLC จริง
CLI sclcเสร็จcompile, import, dump, sim/test, find-decl
IDE SCL Studioเสร็จeditor, tag, interface grid, views, find declaration, highlight, elements panel, recent files
Virtual PLC + Downloadยังไม่ทำออกแบบไว้ในหัวข้อ 07

เริ่มใช้งานเร็ว

  1. build: รัน build.bat (ต้องมี Lazarus ที่ C:\lazarus)
  2. เปิด bin\SCLStudio.exe → File > Open project → examples\FluffSilo\FluffSilo.sclproj
  3. กด Compile (F7) ดูผลใน Messages, Build (F9) ได้ output\FluffSilo.svpl
  4. ทดสอบบน reference VM: sclc --sim output\FluffSilo.svpl --script tests\sequence.txt
แหล่งข้อมูลของหัวข้อนี้
  • โค้ดในโฟลเดอร์ SCLCompiler (สถิติคำนวณจากไฟล์จริง)
  • ผลการรัน run_tests.bat
