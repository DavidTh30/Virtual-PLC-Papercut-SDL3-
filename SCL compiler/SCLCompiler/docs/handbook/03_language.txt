กฎที่ตรวจตาม CPU
--------------------

  • S7-300/400: ไม่มี optimized access (เตือนและใช้ standard), ไม่มี slice access, ไม่มีการแปลง bit string ⇄
    integer แบบ implicit, OB ต้องระบุเลข
  • S7-1200: ไม่มีชนิด 64-bit integer/time (ยกเว้น LReal), ไม่มี S5Time, array index ต้องอยู่ใน -32768..32767
  • S7-1500: รองรับทุกชนิด รวม *_LTIME
  • Implicit conversion: อนุญาตเฉพาะขยายขนาด (Int→DInt→LInt, Int→Real, Real→LReal, Byte→Word...) ที่เหลือต้องใช้
    X_TO_Y
  • ค่าคงที่ตรวจช่วง (เช่น Int := 70000 → error), index คงที่ตรวจ bounds ตอน compile, index แปรผันตรวจตอน runtime


ยังไม่รองรับ
--------------------

  • ANY, POINTER, VARIANT, REF_TO, DB_ANY, Array[*]
  • AT overlay, GOTO / label
  • ฟังก์ชันแปลง String (INT_TO_STRING, STRING_TO_INT ...)
  • S5 timer / counter (T, Z area) ของ S7-300/400
  • System function ของ CPU (RD_SYS_T, PEEK/POKE, communication, ProDiag)
  • EN/ENO (ละไว้)
  • LAD/FBD/STL/GRAPH (รองรับเฉพาะ SCL)


แหล่งข้อมูลของหัวข้อนี้
------------------------
  - โค้ด scl_types (TypeSupportedOn), scl_compiler (ImplicitOK, InferBuiltin)
  - ไฟล์ทดสอบ examples/FeatureTest, examples/ErrorTest
  - ความรู้เรื่องชนิดข้อมูลและ instruction ของ S7 — ควรตรวจกับ TIA Portal Information System หัวข้อ "Data types" และ "SCL instructions"
