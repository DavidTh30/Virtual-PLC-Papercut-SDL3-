เอกสารชุดนี้สรุปโปรแกรม SCL Compiler + SCL Studio ที่สร้างด้วย Lazarus / Free Pascal อย่างละเอียด เพื่อใช้พัฒนาต่อ
รวมถึงการออกแบบ Virtual PLC ที่รองรับการ Download ไฟล์ image จาก IDE

+-----------------------+----------------------------------------------------------------+-------------------+
| ไฟล์                   | หัวข้อ                                                           | เหมาะกับ           |
+=======================+================================================================+===================+
| 01_overview           | ภาพรวมโครงการ สถานะ สถิติ โครงสร้างโฟลเดอร์ เริ่มใช้งาน               | ทุกคน              |
+-----------------------+----------------------------------------------------------------+-------------------+
| 02_architecture       | สถาปัตยกรรม compiler, pipeline, unit และ dependency             | ผู้พัฒนา compiler    |
+-----------------------+----------------------------------------------------------------+-------------------+
| 03_language           | ภาษา SCL ที่รองรับ กฎตาม CPU และข้อจำกัด                            | ผู้ใช้ / ผู้พัฒนา       |
+-----------------------+----------------------------------------------------------------+-------------------+
| 04_compiler_internals | รายละเอียดภายใน: lexer, parser, type system, layout, codegen    | ผู้พัฒนา compiler    |
+-----------------------+----------------------------------------------------------------+-------------------+
| 05_image_format       | รูปแบบไฟล์ .svpl และ memory model                                | ผู้พัฒนา Virtual PLC |
+-----------------------+----------------------------------------------------------------+-------------------+
| 06_instruction_set    | Instruction set, call convention, system FB                    | ผู้พัฒนา Virtual PLC |
+-----------------------+----------------------------------------------------------------+-------------------+
| 07_virtual_plc        | โครงสร้าง Virtual PLC และการรองรับ Download (protocol,           | ผู้พัฒนา Virtual PLC |
|                       | validation, mode)                                              |                   |
+-----------------------+----------------------------------------------------------------+-------------------+
| 08_user_interface     | UI ปัจจุบันของ IDE และ UI พื้นฐานที่ต้องมี (IDE online + Virtual PLC)   | ผู้ออกแบบ UI        |
+-----------------------+----------------------------------------------------------------+-------------------+
| 09_testing            | ชุดทดสอบ ภาษา script และวิธีเพิ่ม test                              | ผู้พัฒนา / QA        |
+-----------------------+----------------------------------------------------------------+-------------------+
| 10_developer_guide    | คู่มือแก้ไข/เพิ่ม feature, coding convention, ข้อควรระวัง FPC/LCL      | ผู้พัฒนา             |
+-----------------------+----------------------------------------------------------------+-------------------+
| 11_recommendations    | คำแนะนำ ความเสี่ยง และ Roadmap                                   | หัวหน้าโครงการ      |
+-----------------------+----------------------------------------------------------------+-------------------+
| 12_references         | แหล่งข้อมูลที่ใช้สร้างแต่ละหัวข้อ และเอกสารที่ควรใช้ตรวจสอบ                 | ทุกคน              |
+-----------------------+----------------------------------------------------------------+-------------------+
| 13_appendix           | Glossary, รูปแบบไฟล์ project/tag, คำสั่ง CLI, คีย์ลัด                 | ทุกคน              |

ทุกหัวข้อมีทั้งไฟล์ .txt (อ่านด้วย text editor) และ .pdf (มีรูปภาพ) และมีไฟล์รวม SCL_Compiler_Handbook.pdf / .txt
รูปภาพทั้งหมดอยู่ในโฟลเดอร์ images/ ทั้งแบบ .svg (แก้ไขได้) และ .png
