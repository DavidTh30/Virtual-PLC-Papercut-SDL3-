  [รูป 6.1] L stack, pending frame และ FB instance  -> images/d06_call_frames.png  (ต้นฉบับ images/d06_call_frames.svg)
 L stack: [OB temps][FB temps][pending FC frame: RET_VAL Input Output InOut][FC temps]
 FC: FrameAlloc -> write params -> Call -> read outputs -> FrameFree
 FB: write inputs to instance -> push instance -> CallFB -> copy outputs


System FB layout (bit offset)
-----------------------------

+-----------------------------------------------------+------------------------------------------------------+
| FB                                                  | layout                                               |
+=====================================================+======================================================+
| Timer (Time) TP/TON/TOF/TONR, *_TIME, IEC_TIMER —   | IN 0, R 1, PT 16, Q 48, ET 64, _ST 96 (Byte), _T0    |
| 22 byte                                             | 112 (LInt)                                           |
+-----------------------------------------------------+------------------------------------------------------+
| Timer (LTime) *_LTIME, IEC_LTIMER — 30 byte         | IN 0, R 1, PT 16, Q 80, ET 96, _ST 160, _T0 176      |
+-----------------------------------------------------+------------------------------------------------------+
| Counter CTU/CTD/CTUD                                | CU 0, CD 1, R 2, LD 3, Q 4, QU 5, QD 6, _CUO 7, _CDO |
|                                                     | 8, PV 16, CV 16+bits(type)                           |
+-----------------------------------------------------+------------------------------------------------------+
| R_TRIG / F_TRIG                                     | CLK 0, Q 1, _M 2                                     |
+-----------------------------------------------------+------------------------------------------------------+
| RS / SR                                             | S 0, R1 1, Q1 2 / S1 0, R 1, Q1 2                    |
+-----------------------------------------------------+------------------------------------------------------+

SysFB id: 1 TP, 2 TON, 3 TOF, 4 TONR, 11–14 แบบ LTime, 20 CTU, 21 CTD, 22 CTUD, 30 R_TRIG, 31 F_TRIG, 32 RS,
