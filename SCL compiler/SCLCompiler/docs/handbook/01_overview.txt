เป้าหมาย
--------------------

  • แปลงโปรแกรม SCL ของ Siemens (S7-300 / S7-400 / S7-1200 / S7-1500) ในรูปแบบ "External source" ของ TIA
    Portal ให้เป็น bytecode
  • ให้มี IDE ภาษาไทย/อังกฤษสำหรับเขียน แก้ไข ตรวจ และ build โปรแกรม SCL โดยไม่ต้องใช้ TIA Portal
  • ผลลัพธ์เป็นไฟล์ image (.svpl) ที่ Virtual PLC (พัฒนาภายหลัง) โหลดและรันได้
  • โครงสร้างหน่วยความจำ DB แบบ standard access ตรงกับ S7 เพื่อให้ HMI เดิมอ่าน/เขียนด้วย address เดิมได้

โครงสร้างโฟลเดอร์
--------------------

    SCLCompiler\
      build.bat            build ทั้ง CLI และ GUI
      run_tests.bat        compile ตัวอย่าง + รันชุดทดสอบ
      README.md            คู่มือย่อ
      bin\                 sclc.exe, SCLStudio.exe
      core\                compiler + image format + reference VM (ไม่มี GUI)
      cli\sclc.lpr         command line
      gui\                 SCLStudio.lpi + sclide_*.pas
      examples\FluffSilo   โปรเจกต์จริง S7-1200 + tests\sequence.txt
      examples\FeatureTest ทดสอบ feature ภาษา (S7-1500)
      examples\ErrorTest   ทดสอบข้อความ error
      docs\SVPL_Spec.md    สเปก image (ฉบับย่อ)
      docs\handbook\       เอกสารชุดนี้ (.txt .pdf images\)


เริ่มใช้งานเร็ว
--------------------

  1. build: รัน build.bat (ต้องมี Lazarus ที่ C:\lazarus)
  2. เปิด bin\SCLStudio.exe → File > Open project → examples\FluffSilo\FluffSilo.sclproj
  3. กด Compile (F7) ดูผลใน Messages, Build (F9) ได้ output\FluffSilo.svpl
  4. ทดสอบบน reference VM: sclc --sim output\FluffSilo.svpl --script tests\sequence.txt
