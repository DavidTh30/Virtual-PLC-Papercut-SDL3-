ภาษา script (sclc --sim image.svpl --script file.txt)
-----------------------------------------------------

+-----------------------------------+------------------------------------------+
| คำสั่ง                              | ความหมาย                                 |
+===================================+==========================================+
| cycle-ms 10                       | เวลาจำลองต่อ cycle                        |
+-----------------------------------+------------------------------------------+
| set <path> <value>                | เขียน tag หรือ "DB".path                   |
+-----------------------------------+------------------------------------------+
| link <input> <output>             | input = output ทุก cycle (จำลอง feedback) |
+-----------------------------------+------------------------------------------+
| run 7s | run 500ms | run 3 cycles | รัน                                       |
+-----------------------------------+------------------------------------------+
| expect <path> <value>             | PASS / FAIL                              |
+-----------------------------------+------------------------------------------+
| print <path>                      | แสดงค่า                                   |
+-----------------------------------+------------------------------------------+
| echo text                         | ข้อความ                                   |
+-----------------------------------+------------------------------------------+


วิธีเพิ่ม test
--------------------

  1. สร้างโปรเจกต์ใน examples/<ชื่อ> (หรือใช้ sclc --import)
  2. เขียน tests/<ชื่อ>.txt ด้วยคำสั่งข้างบน
  3. เพิ่มใน run_tests.bat
  4. ทุกครั้งที่แก้ codegen หรือ opcode ให้รัน run_tests.bat

  [i] หมายเหตุ:
      แนะนำเพิ่ม: เทียบผลกับ PLCSIM / PLC จริงด้วย script เดียวกัน (golden test) และ CI (GitHub Actions + Lazarus)
      เพื่อรันอัตโนมัติ
