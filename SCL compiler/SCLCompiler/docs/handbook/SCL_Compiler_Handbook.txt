เริ่มใช้งานเร็ว
--------------------

  1. build: รัน build.bat (ต้องมี Lazarus ที่ C:\lazarus)
  2. เปิด bin\SCLStudio.exe → File > Open project → examples\FluffSilo\FluffSilo.sclproj
  3. กด Compile (F7) ดูผลใน Messages, Build (F9) ได้ output\FluffSilo.svpl
  4. ทดสอบบน reference VM: sclc --sim output\FluffSilo.svpl --script tests\sequence.txt

สถาปัตยกรรม Compiler   [02_architecture]
##############################################################################################################

  [รูป 2.1] ขั้นตอนการ compile (TSclCompiler.Compile)  -> images/d02_compiler_pipeline.png  (ต้นฉบับ images/d02_compiler_pipeline.svg)
 1 ParseSources -> 2 RegisterBlocks -> 3 AssignNumbers -> 4 RegisterTags -> 5 ResolveBlock
 -> 6 BuildDBImage -> 7 GenerateBlock -> 8 BuildImage -> 9 SaveImage / Listing


หลักการออกแบบ
--------------------

  • แยก core (ไม่มี GUI) ออกจาก IDE — core ใช้ได้ทั้ง CLI, GUI และ test
  • Compile ทั้งโปรเจกต์ทุกครั้ง (เร็ว ~15–200 ms สำหรับ 14 block) จึงไม่มี incremental state ให้ผิดพลาด
  • ส่วนที่ Virtual PLC ต้องใช้ (scl_vmformat, scl_vmmem, scl_vm) ไม่ขึ้นกับ compiler
  • Diagnostics สะสมใน TDiagList: parser กู้คืนจาก error ที่ระดับ statement / block เพื่อรายงานหลาย error พร้อมกัน
  • Address ทุกตัวเป็นหน่วย bit ใน Int64 เดียว → Bool, array of Bool และ struct ใช้กลไกเดียวกัน
  • Code generation แบบ stack machine: ไม่มี register allocation, ง่ายต่อการทำ VM

กฎที่ตรวจตาม CPU
--------------------

  • S7-300/400: ไม่มี optimized access (เตือนและใช้ standard), ไม่มี slice access, ไม่มีการแปลง bit string ⇄
    integer แบบ implicit, OB ต้องระบุเลข
  • S7-1200: ไม่มีชนิด 64-bit integer/time (ยกเว้น LReal), ไม่มี S5Time, array index ต้องอยู่ใน -32768..32767
  • S7-1500: รองรับทุกชนิด รวม *_LTIME
  • Implicit conversion: อนุญาตเฉพาะขยายขนาด (Int→DInt→LInt, Int→Real, Real→LReal, Byte→Word...) ที่เหลือต้องใช้
    X_TO_Y
  • ค่าคงที่ตรวจช่วง (เช่น Int := 70000 → error), index คงที่ตรวจ bounds ตอน compile, index แปรผันตรวจตอน runtime

##############################################################################################################
รายละเอียดภายใน Compiler   [04_compiler_internals]
##############################################################################################################


Lexer (scl_lexer)
--------------------

  • ตัด token ทั้งไฟล์ล่วงหน้า (TokenizeAll) → parser มองไปข้างหน้าได้หลาย token
  • ชื่อ: plain, #local, "global"; keyword เป็น ident แล้ว parser ตัดสินเอง (เพราะชื่ออย่าง IN, MIN, VALUE ใช้เป็น
    parameter ได้)
  • Typed constant: prefix + # → แปลงเป็นค่า (Time = ms, LTime = ns, Date = วันนับจาก 1990-01-01, DT = ms
    นับจาก 1990)
  • Address % อ่านรวมจุด เช่น %DB10.DBX0.0, slice .%X0 ใช้ token เดียวกัน
  • Pragma {...} เก็บ text ไว้ parse เป็น key := value


Parser (scl_parser)
--------------------

  • Recursive descent; precedence: OR < XOR < AND < = <> < < <= > >= < + - < * / MOD < ** < unary <
    postfix
  • REGION: ชื่อคือข้อความที่เหลือของบรรทัด
  • CASE: แยก label กับ statement ด้วย lookahead (ค่า/ชื่อ ตามด้วย : , ..)
  • Error recovery: ข้ามไปที่ ; หรือ END_xxx ของ block แล้วทำต่อ
  • เก็บตำแหน่ง HeaderEndOffset / DeclEndOffset เพื่อให้ grid editor แทนที่ส่วน declaration ได้
  • เก็บ raw text ของ type และ initial value (TypeText / InitText) เพื่อ round-trip


Type system และ layout (scl_types)
----------------------------------

  • TSclType ต่อชนิด; elementary เป็น singleton, composite อยู่ใน type pool (ล้างทุกครั้งที่ compile)
  • Layout แบบ S7 standard: Bool เรียง bit, Byte เริ่ม byte ถัดไป, ชนิดอื่น/Array/Struct/String เริ่ม byte คู่,
    Struct ปัดเป็น byte คู่
  • FB instance: [Input][Output][InOut=Ptr][Static]; FC param: [RET_VAL][Input][Output][InOut]; temp ต่อท้าย
  • System FB: layout คงที่ (ดูหัวข้อ 06) เพื่อให้ VM รู้ offset


Semantic analysis
--------------------

  • InferType(E) คำนวณชนิด + constant folding และ cache ใน node (RType, IsConst, CVal, RefKind, RefOfs,
    ByRef)
  • ชื่อ: local ก่อน (#) แล้ว tag, DB, block; builtin ตรวจเมื่อเรียกแบบ function และชื่อไม่ถูก local ที่เป็น instance บัง
  • CommonType: ชนิดผลของ operator (literal ปรับตามอีกฝั่ง, signed/unsigned ผสม → signed ที่ใหญ่กว่า, int+real →
    real)
  • ImplicitOK: กฎ implicit conversion (ดูหัวข้อ 03)
  • ตรวจ argument ของ FC/FB: ชื่อ parameter, ทิศทาง (:= / =>), InOut ต้องเป็นตัวแปร, FC ต้องกำหนด input ครบ


Code generation
--------------------

+-----------------------------+------------------------------------------------------------------------------+
| รูปแบบ                       | bytecode ที่ได้                                                                 |
+=============================+==============================================================================+
| #a := #b + 1  (Int)         | AddrLocal a · AddrLocal b · Load Int · PushI 1 · AddI · Wrap Int · Store Int |
+-----------------------------+------------------------------------------------------------------------------+
| IF c THEN .. ELSE .. END_IF | eval c · Jz Lelse · ... · Jmp Lend · Lelse: ... · Lend:                      |
+-----------------------------+------------------------------------------------------------------------------+
| CASE x OF 1: .. 4..9: ..    | เก็บ x ใน temp ซ่อน · เทียบทีละ label → Jnz body                                 |
+-----------------------------+------------------------------------------------------------------------------+
| FOR i := a TO b BY s        | temp ซ่อนเก็บ b (และ s ถ้าไม่คงที่) · ตรวจ overflow ก่อนบวก                         |
+-----------------------------+------------------------------------------------------------------------------+
| FC call                     | FrameAlloc · เขียน param ด้วย AddrNewFrame · Call · อ่าน output/RET_VAL ·       |
|                             | FrameFree                                                                    |
+-----------------------------+------------------------------------------------------------------------------+
| FB call                     | เขียน input ลง instance · push instance · CallFB · copy output                |
+-----------------------------+------------------------------------------------------------------------------+
| slice w.%X3 := b            | AddrX w · Dup · Load · (value) · SetBit 3 · Store                            |
+-----------------------------+------------------------------------------------------------------------------+
| String                      | ค่าคือ address; literal อยู่ใน constant pool; CONCAT ใช้ temp String[254]         |
+-----------------------------+------------------------------------------------------------------------------+

  • ทุก block เริ่มด้วย Jmp ไป prologue (ตั้ง max length ของ String temp) แล้วกลับมา
  • Line table: (code offset → บรรทัด) สำหรับ online monitor ในอนาคต
  • Integer ทุกชนิดคำนวณเป็น Int64 แล้ว Wrap ตามชนิด (overflow แบบ S7), Real คำนวณ Double แล้ว F2F32


DB image และ retain
--------------------

  • ApplyDefaults: ค่าเริ่มต้นจาก declaration (รวม instance ซ้อนและ system FB), ตั้ง max length ของ String ทุกตัว
  • BEGIN ของ DB: path := ค่าคงที่ (StaticPath คำนวณ offset)
  • Retain: DB standard ที่ไม่มี keyword = retain ทั้ง block (instance DB = non-retain) · optimized: ตาม VAR
    RETAIN · retainMap 1 bit ต่อ byte


เลข block และ OB
--------------------

  • ลำดับ: [BlockNumbers] ในโปรเจกต์ → ชื่อแบบ DB10/FC3 → ชื่อ OB มาตรฐาน → อัตโนมัติ (OB ≥ 123 สำหรับ 1200/1500)
  • Event class: 1 cycle, 10 time-of-day, 20 delay, 30 cyclic (interval จาก [CyclicInterval] หรือค่ามาตรฐาน
    OB30..38), 40 HW, 80.., 100 startup, 121/122 error


Declaration round-trip (scl_declgen) และ Find Declaration (scl_navigate)
------------------------------------------------------------------------

  • LoadDeclRows: parse source → แถว (section, name, type text, init, retain, comment)
  • ApplyDeclRows: สร้าง VAR sections / STRUCT ใหม่แล้วแทนที่ช่วง HeaderEnd..DeclEnd ของ block นั้น
  • FindDeclarationAt: แยก path ใต้ cursor (#a.b[i].c) → local / DB member / tag / block → ไล่ member
    ทีละชั้นด้วย TSclType → DeclPos

Load protocol (ข้อเสนอ v1, TCP port 10102)
-----------------------------------------

    Frame (little endian)
     0  u16  magic 'SV'
     2  u8   protocol version = 1
     3  u8   command / response code (response = command | 0x80, error = 0x7F)
     4  u32  sequence number (response คืนค่าเดียวกัน)
     8  u32  payload length n
    12  n    payload
    12+n u32 CRC32 (byte 0 .. 12+n-1)

+-------+------------------------+-------------------------------------+-------------------------------------+
| code  | command                | payload คำขอ                        | payload ตอบ                         |
+=======+========================+=====================================+=====================================+
| 01    | HELLO                  | client name, protocol ver, password | cpu, vplc version, memory limits,   |
|       |                        | hash (SHA-256)                      | mode, image name, image SHA-256     |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 02    | GET_STATE              | -                                   | mode, cycle min/avg/max, last error |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 03    | SET_MODE               | 0 STOP, 1 RUN warm, 2 RUN cold, 3   | mode ใหม่                            |
|       |                        | memory reset                        |                                     |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 10    | DOWNLOAD_BEGIN         | size u32, SHA-256, flags            | max chunk size                      |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 11    | DOWNLOAD_CHUNK         | offset u32, data                    | received bytes                      |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 12    | DOWNLOAD_END           | -                                   | VALID / รายการ error                |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 13    | ACTIVATE               | flags: keep retain, reset DB start  | ผล                                  |
|       |                        | values, start after                 |                                     |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 14    | DOWNLOAD_ABORT         | -                                   | -                                   |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 18    | UPLOAD                 | offset, length                      | ข้อมูล active.svpl                    |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 20/21 | READ_VARS / WRITE_VARS | รายการ (address i64, vmType) / +    | values / status                     |
|       |                        | value                               |                                     |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 22    | FORCE                  | address, type, value / unforce      | status                              |
+-------+------------------------+-------------------------------------+-------------------------------------+
| 30    | READ_DIAG              | from index                          | รายการเหตุการณ์                       |
+-------+------------------------+-------------------------------------+-------------------------------------+

Validation ก่อน activate (ต้องทำครบ)
----------------------------------

  1. magic, version, CPU family ตรงกับที่ Virtual PLC ตั้งไว้
  2. SHA-256 ของไฟล์ตรงกับ DOWNLOAD_BEGIN
  3. ทุก section อ่านได้ ไม่เกินขอบไฟล์, string offset ถูกต้อง
  4. ทุก block: เดิน bytecode ตาม OpOperands — opcode รู้จัก, operand ไม่เกินขอบ, jump ตกที่ต้นคำสั่ง, Call ชี้ FC,
     CallFB ชี้ FB, SysFB id รู้จัก, vmType ถูกต้อง
  5. DB number ไม่ซ้ำ, ขนาดอยู่ในขีดจำกัด, tag อยู่ในขนาด process image
  6. มี OB event class 1 อย่างน้อย 1 ตัว (เตือนถ้าไม่มี)
  7. คำนวณ stack depth สูงสุดคร่าว ๆ (ทางเลือก) เพื่อกัน stack overflow


Activate และ retain
--------------------

  • Activate ทำได้เฉพาะ STOP; สลับ image แบบ atomic (เขียน active.svpl.new แล้ว rename)
  • Keep retain: DB ที่เลข/ชื่อ/ขนาด (และ layout hash ในอนาคต) ตรงกัน → copy byte ที่ retainMap = 1 จาก memory
    เดิม; ไม่ตรง → ใช้ start value และบันทึกใน diagnostic buffer
  • Reset DB start values: ใช้ค่าในไฟล์ทั้งหมด
  • Retain store: บันทึก retain.bin (+CRC) ตอน STOP, ปิดโปรแกรม และทุก N วินาที


Runtime loop (pseudo code)
--------------------------

    procedure TRuntime.Execute;            // thread
    begin
      while not Terminated do
      begin
        ApplyPendingModeChange;            // จาก comm thread ผ่าน queue
        case Mode of
          pmStartup: begin RunOBs(100); Mode := pmRun; end;
          pmRun:
            begin
              T0 := Now;
              Io.ReadInputs(Mem.I);
              ApplyForces;
              RunOBs(1);                     // OB1 แล้ว OB123+ เรียงเลข
              RunCyclicOBsDue;               // OB30..38
              ApplyForces;
              Io.WriteOutputs(Mem.Q);
              Stats.Add(Now - T0);
              if Now - T0 > Watchdog then GoError('cycle time exceeded');
              WaitMinCycle(T0);
            end;
        else
          Sleep(10);
        end;
      end;
    end;


Threading และความปลอดภัย
-----------------------

  • Runtime 1 thread, comm 1 thread ต่อ client; การเข้าถึง memory จาก comm (monitor/HMI) ทำที่ขอบ cycle หรือใช้
    critical section สั้น ๆ
  • Watchdog: interpreter นับคำสั่ง ทุก 10,000 คำสั่งตรวจเวลา → ยกเลิก cycle และเข้า ERROR
  • Output safe state เมื่อเข้า STOP/ERROR (ค่าเริ่มต้น = 0)
  • Password + session lock สำหรับ download / write / force
  • Log ทุก download (เวลา, ผู้ใช้, hash) ใน diagnostic buffer

    type
      TPlcMode = (pmNoProgram, pmStop, pmStartup, pmRun, pmError);

เพิ่ม builtin function ใหม่
------------------------

  1. เพิ่มชื่อใน IsBuiltinName (scl_compiler)
  2. กำหนดชนิด argument/ผลลัพธ์ใน InferBuiltin
  3. สร้าง bytecode ใน EmitBuiltin (ใช้ opcode เดิม หรือเพิ่ม BI_xxx ใน opBuiltin)
  4. ถ้าเพิ่ม BI_xxx: implement ใน scl_vm.pas และบันทึกใน SVPL_Spec
  5. เพิ่ม element ใน sclide_elements (BuildStatic) และ test ใน FeatureTest


เพิ่ม opcode
--------------------

  1. เพิ่มท้าย TOpcode (อย่าแทรกกลาง — เลข opcode เปลี่ยน)
  2. กำหนด operand ใน OpOperands
  3. implement ใน TVirtualPlc.Execute
  4. ปรับ SVPL_VERSION ถ้าไม่เข้ากันย้อนหลัง
  5. อัปเดต docs/SVPL_Spec.md และหัวข้อ 06


เพิ่มชนิดข้อมูล / system FB
----------------------

  • ชนิด: TTypeKind (เลขต่อจากเดิม = VM type code), ElementaryBits, TypeSupportedOn, Load/Store ใน scl_vmmem
  • System FB: ตาราง SysFBs + MakeSysFBType (layout), SysFBId, implement ใน TVirtualPlc.SysFB, เพิ่ม element
    ใน panel


เพิ่ม panel / แท็บใน GUI

  • GUI สร้างด้วยโค้ด (ไม่มี .lfm) — form ใช้ CreateNew
  • ผูกกับ compile: เรียกใน RunCompile หลัง RebuildTree


Coding convention
--------------------

  • {$mode objfpc}{$H+}, ชื่อ field ขึ้นต้น F, type ขึ้นต้น T, ห้ามใช้ with ซ้อน
  • core ห้าม uses LCL
  • ข้อความ error เป็นภาษาอังกฤษสั้น มีชื่อ/ค่า
  • ทุก unit core มี header comment บรรทัดแรก

คำแนะนำสำคัญ
--------------------

  1. ตรวจกับของจริงก่อนขยาย: import FluffSilo เข้า TIA Portal เทียบ offset ของ DB และพฤติกรรม (PLCSIM) เพื่อยืนยันกฎ
     layout/conversion
  2. สร้าง Virtual PLC จาก scl_vm.pas ก่อน (ทำงานถูกแล้วกับ 109 checks) แทนการเขียนใหม่
  3. ทำ Download แบบ STOP-only ก่อน, run-time download ไว้ทีหลัง
  4. เพิ่ม layout hash ต่อ DB และ hash ทั้ง image (SVPL v2) เพื่อ keep retain และ compare online/offline
     อย่างปลอดภัย
  5. ล็อก format: ทุกการเปลี่ยน opcode/section ต้องเพิ่ม version และมี test
  6. ความปลอดภัย: Virtual PLC ห้ามใช้แทน safety PLC / E-Stop ต้องเป็น hardware; เปิด password และจำกัด network ของ
     PUT/GET
  7. ประสิทธิภาพ: ถ้า cycle ยาว ให้ทำ pre-decode bytecode เป็น array ของ record (ไม่ต้องอ่าน operand ทุกครั้ง) ก่อนคิด
     JIT
  8. License: Lazarus LCL (modified LGPL), SynEdit (MPL/GPL dual), Snap7 (LGPL3) —
     ตรวจเงื่อนไขก่อนแจกจ่ายเชิงพาณิชย์

Glossary
--------------------

+-----------------------------+------------------------------------------------------------------------------+
| คำ                          | ความหมาย                                                                     |
+=============================+==============================================================================+
| SCL                         | Structured Control Language — ภาษาแบบ ST (IEC 61131-3) ของ Siemens           |
+-----------------------------+------------------------------------------------------------------------------+
| OB / FB / FC / DB / UDT     | Organization block / Function block (มี instance) / Function / Data block /   |
|                             | PLC data type                                                                |
+-----------------------------+------------------------------------------------------------------------------+
| Instance DB                 | DB ที่เก็บหน่วยความจำของ FB หนึ่งตัว                                                |
+-----------------------------+------------------------------------------------------------------------------+
| Multi-instance              | FB ซ้อนอยู่ใน static ของ FB อื่น                                                  |
+-----------------------------+------------------------------------------------------------------------------+
| Standard / optimized access | DB ที่มี offset ตายตัว (HMI ใช้ address ได้) / ไม่มี offset ภายนอก                   |
+-----------------------------+------------------------------------------------------------------------------+
| Retain                      | ค่าที่คงอยู่หลังไฟดับ                                                               |
+-----------------------------+------------------------------------------------------------------------------+
| Image (.svpl)               | ไฟล์ผลลัพธ์ของ compiler ที่ Virtual PLC โหลด                                      |
+-----------------------------+------------------------------------------------------------------------------+
| Pending frame               | frame ของ FC ที่ caller จองเพื่อใส่ parameter ก่อนเรียก                             |
+-----------------------------+------------------------------------------------------------------------------+
| Download                    | ส่ง image จาก IDE ไปยัง Virtual PLC                                            |
+-----------------------------+------------------------------------------------------------------------------+
| PUT/GET                     | บริการอ่าน/เขียนหน่วยความจำของ S7 ที่ HMI ใช้                                       |
+-----------------------------+------------------------------------------------------------------------------+
