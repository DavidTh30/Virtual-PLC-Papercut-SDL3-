  [รูป 2.1] ขั้นตอนการ compile (TSclCompiler.Compile)  -> images/d02_compiler_pipeline.png  (ต้นฉบับ images/d02_compiler_pipeline.svg)
 1 ParseSources -> 2 RegisterBlocks -> 3 AssignNumbers -> 4 RegisterTags -> 5 ResolveBlock
 -> 6 BuildDBImage -> 7 GenerateBlock -> 8 BuildImage -> 9 SaveImage / Listing


หลักการออกแบบ
--------------------

  • แยก core (ไม่มี GUI) ออกจาก IDE — core ใช้ได้ทั้ง CLI, GUI และ test
  • Compile ทั้งโปรเจกต์ทุกครั้ง (เร็ว ~15–200 ms สำหรับ 14 block) จึงไม่มี incremental state ให้ผิดพลาด
  • ส่วนที่ Virtual PLC ต้องใช้ (scl_vmformat, scl_vmmem, scl_vm) ไม่ขึ้นกับ compiler
  • Diagnostics สะสมใน TDiagList: parser กู้คืนจาก error ที่ระดับ statement / block เพื่อรายงานหลาย error พร้อมกัน
  • Address ทุกตัวเป็นหน่วย bit ใน Int64 เดียว → Bool, array of Bool และ struct ใช้กลไกเดียวกัน
  • Code generation แบบ stack machine: ไม่มี register allocation, ง่ายต่อการทำ VM


ลำดับขั้นตอน
--------------------

+----+-------------------------+-----------------------------------------------------------------------------+
| ขั้น | method                  | รายละเอียด                                                                   |
+====+=========================+=============================================================================+
| 1  | ParseSources            | อ่านทุกไฟล์ใน [Sources] (หรือ buffer จาก editor ผ่าน OnGetSource) →              |
|    |                         | TSourceUnitList                                                             |
+----+-------------------------+-----------------------------------------------------------------------------+
| 2  | RegisterBlocks          | สร้าง TBlockInfo ต่อ block, ตรวจชื่อซ้ำ, optimized access ตาม CPU                |
+----+-------------------------+-----------------------------------------------------------------------------+
| 3  | AssignNumbers           | เลข block จาก [BlockNumbers], ชื่อแบบ DB10/FC5, ชื่อ OB มาตรฐาน (Main=1,        |
|    |                         | Startup=100), อัตโนมัติ; event class ของ OB                                    |
+----+-------------------------+-----------------------------------------------------------------------------+
| 4  | RegisterTags            | tag CSV → address (MakeAddr) + type, ตรวจขนาด address/type, user constant   |
+----+-------------------------+-----------------------------------------------------------------------------+
| 5  | ResolveBlock            | สร้าง TSclType ของ UDT/DB/FB instance/FC param/temp, layout, local symbol    |
|    |                         | table (recursive พร้อมตรวจ cycle)                                            |
+----+-------------------------+-----------------------------------------------------------------------------+
| 6  | BuildDBImage            | start value จาก declaration + BEGIN, retain map                             |
+----+-------------------------+-----------------------------------------------------------------------------+
| 7  | GenerateBlock           | type check + emit bytecode ต่อ block, line table, prologue สำหรับ String temp |
+----+-------------------------+-----------------------------------------------------------------------------+
| 8  | BuildImage              | รวมเป็น TSvImage: block table, DB, tags, vars table, constant pool           |
+----+-------------------------+-----------------------------------------------------------------------------+
| 9  | SaveImage / ListingText | เขียน .svpl, .lst (disassembly), .map.txt                                    |
+----+-------------------------+-----------------------------------------------------------------------------+
